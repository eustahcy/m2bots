Uszkodzona tabela bazy danych

{% if table %}Tabela {{ table }}{% else %}Jedna z tabel bazy{% endif %} jest oznaczona jako uszkodzona, więc panel nie może jej odczytać. Silnik gry używa tabel MyISAM, a te nie przeżywają nagłego zatrzymania — wystarczy zamknięcie Dockera w trakcie zapisu albo zanik zasilania.

Aktualizacja serwera tego nie naprawi. Uszkodzenie jest w danych na dysku, a nie w programie — nowa wersja czyta te same pliki.

Jak naprawić

Otwórz terminal w folderze serwera, w podkatalogu linux-port/docker, i uruchom:

docker compose exec mariadb mysqlcheck -uroot -p --auto-repair --databases log player account common

Zapyta o hasło — to M2_DB_ROOT_PASSWORD z pliku .env w tym samym folderze. Naprawa dużej tabeli logów potrafi potrwać kilka minut.

Jeśli naprawa się nie uda

Baza log to wyłącznie historia: co kto podniósł, ulepszył i powiedział. Gra jej nie czyta i żadna postać, przedmiot ani bot od niej nie zależą. Jeśli mysqlcheck zgłosi, że nie da rady, te tabele można opróżnić bez straty dla świata:

docker compose exec mariadb mariadb -uroot -p -e "TRUNCATE log.log; TRUNCATE log.levellog; TRUNCATE log.shout_log;"
Nie rób tego dla baz player, account ani common — tam są postacie, konta i boty.
